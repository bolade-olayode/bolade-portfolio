## The platform

Albis Care supports the daily work of a UK domiciliary care provider. Care staff record visits and care notes, the office coordinates clients and staff, and relatives can view updates shared with them about their family member.

## My contribution

I have been the sole engineer and technical owner since 2024. I built the PHP REST API and database, the React Native app, the access model, and the WordPress website enquiry integration. I also handle mobile builds, Google Play releases, and ongoing maintenance.

## Care records and access

The access model distinguishes administrative responsibilities from recording care. Assigned staff write notes for the care they deliver. Relatives receive access for a specific client, with permissions that can be adjusted or withdrawn. Backend checks enforce access to records and actions.

## Delivery

The platform uses a PHP REST API and MySQL/MariaDB with a React Native/Expo app. WordPress and Elementor support the marketing website. Website enquiries follow a separate workflow from care records. EAS Build and GitHub Actions support mobile releases.

## Current use

The platform is live and used daily by the provider. Public screenshots are limited to interface views, with identifying details redacted where necessary. Screenshot totals are not reported usage figures.
